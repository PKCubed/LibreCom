# RP2040 Speech Link (PCM1808 -> UART -> PCM5102A)

This project builds **two firmware images**:
- `adc_tx.uf2`: captures mono speech from PCM1808, ADPCM-compresses it, sends via UART.
- `dac_rx.uf2`: receives ADPCM stream via UART, decodes, plays mono on **both** L/R channels to PCM5102A.

## Wiring

### Board A (`adc_tx`)
- PCM1808 `SCK` -> GPIO0 (MCLK generated by RP2040)
- PCM1808 `BCK` -> GPIO1
- PCM1808 `LRC` -> GPIO2
- PCM1808 `DOUT` -> GPIO3
- UART TX -> GPIO4 -> Board B GPIO5
- Shared GND between both boards and audio boards

### Board B (`dac_rx`)
- UART RX <- GPIO5 (from Board A GPIO4)
- PCM5102A `DIN` <- GPIO6
- PCM5102A `BCK` <- GPIO7
- PCM5102A `LCK/LRCK` <- GPIO8
- Shared GND

## Audio format
- Mono speech
- 8 kHz sample rate
- 20 ms frames (160 samples)
- IMA ADPCM (4-bit/sample)

Approx stream payload bitrate is ~32 kbps plus framing overhead.

## Build prerequisites
- Raspberry Pi Pico SDK checked out locally
- `PICO_SDK_PATH` environment variable set to that SDK path
- ARM GCC (`arm-none-eabi-gcc`) in PATH
- CMake + Ninja

## Build

```powershell
cmake -S . -B build -G Ninja
cmake --build build -j
```

Expected artifacts:
- `build/adc_tx.uf2`
- `build/dac_rx.uf2`

## Flash
1. Hold BOOTSEL and plug Board A, copy `build/adc_tx.uf2`.
2. Hold BOOTSEL and plug Board B, copy `build/dac_rx.uf2`.

## Notes
- PCM1808 MCLK on GPIO0 is generated by PWM at ~12.5 MHz.
- If capture sounds distorted, adjust MCLK/BCK/LRCK mode straps on your PCM1808 board and verify I2S format.
- This implementation is optimized for intelligible speech and reliability over one-wire UART transport.
